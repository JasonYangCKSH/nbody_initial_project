# Collision Lab：寬相碰撞偵測互動 DEMO

以瀏覽器即時展示粒子系統的 **Broad-Phase 碰撞偵測**，比較暴力法、均勻網格（Uniform Grid）與八元樹（Octree），並視覺化 **Verlet List 的 skin 機制**：skin 依粒子瞬時速度與加速度動態計算，並受空間結構的幾何上界限制。

本 DEMO 對應專題論文〈異質動態粒子場景下整合八元樹空間分割與 Verlet List 自適應更新之碰撞偵測〉。論文的實驗數據由另一份 C++ 實作產生，這個 DEMO 用來直觀說明同一套機制在做什麼。

## 快速開始

需要 **Node.js 20.19 以上或 22.12 以上**（Vite 7 的要求）。

```bash
npm install
npm run dev
```

打開終端機顯示的網址（預設 `http://localhost:5173/`）。

其他指令：

| 指令 | 用途 |
|---|---|
| `npm test` | 執行單元測試（Vitest） |
| `npm run build` | 型別檢查並建置正式版到 `dist/` |
| `npm run preview` | 預覽建置結果 |

## 核心概念與對應程式

| 概念 | 說明 | 程式位置 |
|---|---|---|
| 暴力法 | 所有粒子兩兩比對，O(n²)；作為正確性基準 | `src/core/spatial/BruteForceStructure.ts` |
| 均勻網格 | 固定大小的格子，只比對相鄰格子；skin 上界為 `cellSize / 2 − r`（論文式 3） | `src/core/spatial/UniformGridStructure.ts` |
| 八元樹 | 格子內粒子超過容量就切成 8 格，密集處切得更細；skin 上界為 `葉節點半邊長 − r`（論文式 4） | `src/core/spatial/OctreeStructure.ts` |
| 動態 skin | `skin = K·|v|·Δt + ½·|a|·(K·Δt)²`（論文式 1） | `VerletBufferController.computeSkin()` |
| 重建判定 | 任一粒子自上次重建起的累積位移 `Δx > skin` 就重建（論文式 2） | `VerletBufferController.isListValid()` |
| 一步模擬流程 | 判定是否重建 → 寬相 → 窄相 → 碰撞回應 → 積分（論文圖 2） | `src/App.tsx` 的 `step()` |

播放速度只改變「多久跑一步」，每一步的物理時間 `dt = 1/60` 固定，所以結果不受播放速度影響。

## 功能

### 分析與視覺化
- **三種空間結構**即時切換，顯示距離檢查數、候選配對、碰撞數、重建次數、跳過比例，以及寬相／窄相耗時曲線。
- **事件記錄**：每次重建記錄「超出自己 skin 最多」的觸發粒子、累積位移與 skin。只在 Verlet 緩衝開啟、真的有粒子超出 skin 時記錄。
- **八元樹切割畫面**：依層級上色；層級清單列出每層的邊長、葉節點數與已切開數；可多選層級，可用虛線顯示已再切開的格子，也可只顯示選取層級的粒子。
- **觸發粒子定位**：最近觸發重建的粒子標成紫色，並加上圓環、光柱與 skin 線框球。
- **粒子資訊面板**：點擊粒子或事件即可查看位置、速度、加速度、skin、skin 上界、累積位移（佔 skin 的比例）、所在葉節點的層級與大小、格子容量與觸發重建次數。

### 場景
- **粒子雲**：均勻或群聚分布，可調整群聚係數與群聚中心數。
- **煙火爆炸**：1～8 發煙火在空中不同位置炸開，快慢不一的火花受重力落下；夜空、星星、草地，炸開時照亮地面。同一個場景同時呈現**密度異質**（中心極密 → 逐漸散開）與**速度異質**。

### 操作
- 中英文介面切換。
- 播放速度 0.25×～4×，顯示目標與實際每秒步數。
- 鏡頭對準選取的粒子、重設視角。

| 場景 | 按鍵／滑鼠 | 作用 |
|---|---|---|
| 粒子雲 | W/A/S/D、Q/E、Shift | 移動鏡頭、上下、加速 |
| 粒子雲／煙火的自由視角 | 拖曳滑鼠 | 旋轉場景 |
| 煙火 | W/A/S/D、Q/E、Shift | 觀眾走動、轉向、跑步 |
| 煙火的觀眾視角 | 點一下畫面 → 移動滑鼠 → Esc | 鎖定滑鼠、轉動視角（Minecraft 式）、放開滑鼠 |

### 阻擋者小遊戲（煙火場景）
守衛站在金色光圈（最佳觀賞位置）前方擋住煙火。走到攻擊距離內，用準心對準並點擊把他們打倒；站進光圈且視野 100% 時累計最佳觀賞時間。阻擋判定以「眼睛到每發煙火中心的視線」是否被守衛擋住計算，見 `src/core/blockers.ts`。

## 建議的演示流程（約 3 分鐘）

1. **暴力法**：粒子數拉到 1 萬以上，觀察距離檢查數達數千萬次、畫面變慢。
2. **切到八元樹**：檢查數降到數十萬；開啟「顯示八元樹切割」，多選第 3 層與第 6 層，說明群聚處切得更細。
3. **開啟 Verlet 緩衝**：跳過比例上升，紫色觸發粒子出現；點選它，從粒子資訊說明累積位移剛超過 skin、所在格子較深、skin 上界較小。
4. **煙火爆炸**：按「再爆一次」，觀察八元樹格子從中心的深層小格逐漸變成外圍的淺層大格，以及重建頻率的變化。

## 已知限制

- 模擬在瀏覽器主執行緒上計算；粒子數上萬時使用暴力法，每一步可能要數秒，期間畫面無法操作。
- 八元樹找候選配對時會比較每一對葉節點是否重疊，葉節點很多時較慢。
- 觀眾視角的滑鼠鎖定需要瀏覽器支援 Pointer Lock，建議使用 Chrome。
